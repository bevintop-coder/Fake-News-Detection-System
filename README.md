# Fake-News-Detection-System
An AI-powered NLP application that analyzes news content using machine learning techniques to classify articles as real or fake.

# 📰 Fake News Detection System

A machine learning based fake news detection application.

## Features

- NLP text analysis
- Fake/Real news classification
- Web interface
- Java implementation
- Machine learning model


## Technologies

Python
Java
HTML
CSS
JavaScript
Machine Learning
NLP


## How it Works

User enters news text.

The system analyzes the text using NLP techniques.

Machine learning model predicts whether the news is REAL or FAKE.
